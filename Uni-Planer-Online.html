            Eigene Vokabeln hinzufügen

            Eigene Vokabeln kommen bevorzugt als nächste neue Karten dran und laufen dann im normalen Wiederholungs-Rhythmus mit.

            Alle Vokabeln nach Kategorie

            An jedem Übungstag kommen genau 10 neue Vokabeln dazu. „Kann ich noch nicht“ → kommt in derselben Runde gleich nochmal, „Mittel“ → in 3 Tagen, „Kann ich“ → in wachsenden Abständen (3, 7, 14, 30, 60 Tage). Nach der Runde kannst du endlos weiterüben (alle gelernten Vokabeln, immer neu gemischt) – das verändert die Lernabstände nicht zusätzlich.

            Synchronisierung – eigenes Konto (ohne Claude)

            …

            Mit demselben Konto auf iPad, Handy und Laptop anmelden – Aufgaben, Termine, Lernpläne, Vokabeln und deine Fotos sind dann überall synchron.

            Synchronisiert automatisch: kurz nach jeder Änderung, beim Öffnen der Seite und alle 5 Minuten. „Abmelden“ stoppt nur den Abgleich – deine Einträge bleiben auf dem Gerät.

            Einrichtung Teil 1: Firebase-Konto (einmalig, ca. 10 Minuten)
            1. Öffne console.firebase.google.com und melde dich mit einem Google-Konto an.
            2. „Projekt erstellen“ → Name z. B. uni-planer → Google Analytics kannst du ausschalten → erstellen.
            3. Links im Menü Authentication → „Jetzt starten“ → Anmeldemethode E-Mail/Passwort aktivieren → speichern.
            4. Links im Menü Realtime Database → „Datenbank erstellen“ → Standort Belgien (europe-west1) → „Im gesperrten Modus starten“ → aktivieren.
            5. Oben auf den Reiter Regeln → den vorhandenen Text komplett durch den folgenden ersetzen und auf Veröffentlichen klicken: 
              {
  "rules": {
    "users": {
      "$uid": {
        ".read": "auth != null && auth.uid === $uid",
        ".write": "auth != null && auth.uid === $uid"
      }
    }
  }
}
            6. Im Reiter Daten steht oben die Adresse https://…firebasedatabase.app – das ist die Datenbank-URL für unten.
            7. Zahnrad neben „Projektübersicht“ (oben links) → Projekteinstellungen → unter „Allgemein“ steht der Web-API-Schlüssel.
            8. Beide Werte hier eintragen und speichern – danach oben einmal „Neues Konto erstellen“. Der Web-API-Schlüssel ist kein Geheimnis; deine Daten schützt das Passwort zusammen mit den Regeln aus Schritt 5.
            Einrichtung Teil 2: Eigene Webadresse über GitHub (einmalig)
            1. Öffne github.com und erstelle ein kostenloses Konto.
            2. Oben rechts + → „New repository“ → Name uni-planer → „Public“ → Haken bei „Add a README file“ → „Create repository“.
            3. „Add file“ → „Upload files“ → die Datei Uni-Planer-Online.html vom Desktop hineinziehen → „Commit changes“.
            4. „Settings“ → links Pages → bei „Branch“ main und „/ (root)“ wählen → „Save“.
            5. Nach 1–2 Minuten ist dein Planer erreichbar unter https://DEIN-NAME.github.io/uni-planer/Uni-Planer-Online.html. Diese Adresse auf iPad und Handy öffnen und über „Zum Home-Bildschirm hinzufügen“ wie eine App anheften.
            6. Neue Version später einspielen: dieselbe Datei einfach noch einmal hochladen – sie ersetzt die alte. Im Repository liegt nur der Seiten-Code; deine Einträge liegen geschützt hinter deinem Login bei Firebase.
            Darstellung
            Semester

            Mit gesetztem Zeitraum zeigt die Seitenleiste die aktuelle Semesterwoche und die Lernwoche trägt die SW-Nummer im Titel.

            Gruppen in der Seitenleiste

            Benenne die Oberthemen um, unter denen deine Vorlesungen gruppiert sind. Der neue Name gilt für alle Fächer der Gruppe.

            Wochenziele

            Setze dir Ziele pro Woche – der Wochenrückblick auf der Startseite zeigt dann Fortschrittsbalken. Feld leer lassen = kein Ziel.

            Notenübersicht

            Banner – Fotostreifen oben auf jeder Ansicht
            Hintergrund – Foto hinter der ganzen Seite (leicht aufgehellt)
            Export & Sicherung

            Die CSV-Datei lässt sich in Google Kalender über „Einstellungen → Importieren“ einlesen. Das Backup enthält alle Vorlesungen, Aufgaben, Termine und Lernblöcke.

            Aufräumen & Speicher

            Foto-Upload ist gerade nicht verfügbar – bitte Seite neu laden.

            Termine aus Kalenderdatei (.ics) importieren

            Eine .ics-Datei bekommst du aus den meisten Uni-Portalen („Stundenplan/Kalender exportieren“) sowie aus Apple-, Google- und Outlook-Kalendern. Enthält der Termintitel einen Fachnamen, wird er automatisch der Vorlesung zugeordnet; steht „Klausur“ im Titel, wird er rot als Klausur markiert. Wöchentlich wiederkehrende Serientermine werden automatisch ausgerollt (bis zu 60 Wiederholungen).
